DSA simply stands for Data Structure and Algorithm, In this we learn about how the code can be more efficient and how the code can be scalable and optimized. We learn various data structure for different purposes and use case than use those data structures in algorithims to get our desire results.

We already talked about real life problems and how we solve them. But it doesn't mean we can solve all the problems with our basic thoughts, we need to learn something to solve them, and that something is DSA.
